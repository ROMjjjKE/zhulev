# ИП Жулев Александр Владимирович — замена кухонных фасадов и столешниц. Могилёв

Шесть страниц: index, uslugi, raboty, o-masterskoy, kontakty, politika.

Арт-дирекция: тёмно-зелёный холст #16261E как основной фон, бумажная вставка #F1ECE5 для образцов, латунь #C2913F. Шрифты: Alegreya (антиква, курсив в заголовках) и Source Sans 3.

Приёмы: полоса этапов под героем, редакционный блок «кухня не старая, она просто устала», рейка из четырёх образцов материалов (ЛДСП, эмаль, шпон, столешница) с переключением карточки и честной строкой «что учитывать».

Критический CSS встроен в style до ссылки на assets/css/style.v1.css.

## Перед запуском
1. УНП в подвал и политику.
2. Реальные фото кухонь вместо сгенерированных.
3. В брифе «ремонт» без расшифровки. На сайте он раскрыт как замена петель и фурнитуры, кромка, провисшие двери. Подтвердить, что это входит.
4. Подтвердить материалы: ЛДСП, МДФ в эмали, шпон, кварц и акриловый камень. В брифе только «множество вариантов».
